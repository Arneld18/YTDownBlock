# YTDownBlock

**YTDownBlock** is a lightweight, premium Free Windows application designed to enhance your YouTube experience. It combines a powerful ad-blocking browser with high-quality video and audio download capabilities, all wrapped in a sleek, modern interface.

## ✨ Key Features

- **🚫 Advanced Ad-Blocking**: Enjoy YouTube without interruptions. Automatically blocks video ads, banners, and annotations.
- **🎥 High-Quality Video Downloads**: Supports resolutions up to 4K Ultra HD and 2K Quad HD.
- **🎵 MP3 Audio Extraction**: Convert any video to high-quality MP3 (320kbps supported) with automatic cover art and metadata embedding.
- **⚡ Smart Download Manager**: Circular progress indicators and a floating popover to keep track of multiple downloads without cluttering the screen.
- **🌐 Multilingual Support**: Fully localized in English and Spanish.
- **🎨 Premium Interface**: Modern dark theme with smooth animations and responsive controls.
- **🛡️ Privacy Focused**: Clean and secure browsing experience.

## 🚀 Installation & Setup

1. **Download the Installer**: Obtain the latest `YTDownBlock_Setup.exe` from the releases page.
2. **Run the Installer**: Follow the on-screen instructions to install the application.
3. **Dependencies**:
    - **WebView2**: The app uses the Microsoft Edge WebView2 runtime. If not already present, the app will prompt you to install it or you can download it from [Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/).
    - **FFmpeg (Built-in):** Essential for high-definition video merging and MP3 conversion. Unlike other tools, **you do not need to install FFmpeg separately**; it is already bundled within the application for a seamless "plug-and-play" experience.

---

## 🛠 How to Use

1. **Browse**: Open the app and navigate to any YouTube video.
2. **Select Quality**: Use the capsule-style dropdowns in the toolbar to choose your preferred video resolution or audio bitrate.
3. **Download**: Click the green **"Add to Queue"** button.
4. **Manage**: Click the tray icon or the download button in the toolbar to view the floating popover with your active downloads and progress.
5. **Enjoy**: Once completed, play the file directly from the app or open its containing folder.

## ⚙️ Requirements

- **OS**: Windows 10 or 11 (64-bit recommended)
- **Runtime**: .NET 8.0 or higher
- **Browser Runtime**: Microsoft Edge WebView2
- **Additional**: FFmpeg (for HD and MP3 features)
