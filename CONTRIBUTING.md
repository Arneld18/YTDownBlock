# Contributing to YTDownBlock

Thank you for your interest in contributing to **YTDownBlock**! We welcome contributions from the community to help make this tool even better.

## 🛠 Getting Started

1. **Fork the Repository**: Create your own copy of the project.
2. **Clone Locally**: `git clone https://github.com/arnel/YTDownBlock.git`
3. **Environment**: Ensure you have Visual Studio 2022 or higher and the .NET 8.0/10.0 SDK installed.
4. **Build**: Open `YTDownBlock.sln` and build the solution to ensure everything is set up correctly.

## 🤝 How to Contribute

- **Report Bugs**: Use the GitHub Issues tracker to report bugs. Please provide clear steps to reproduce the issue.
- **Suggest Features**: If you have an idea for a new feature, open an issue to discuss it.
- **Pull Requests**:
    - Create a new branch for your feature or bug fix (`git checkout -b feature/your-feature-name`).
    - Commit your changes with clear, descriptive messages.
    - Push to your fork and submit a Pull Request.

## 📜 Coding Guidelines

- Maintain the existing coding style (C# / XAML).
- Ensure all new features are localized in `Strings.en.xaml` and `Strings.es.xaml`.
- Keep the UI clean and minimalist.
- Verify that your changes build and run without errors.
